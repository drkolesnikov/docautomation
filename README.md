# ПНД.doc

Веб-приложение для автоматизации клинической документации в психоневрологическом диспансере.

Врач вводит свободные заметки, выбирает тип документа — приложение формирует готовый структурированный документ через LLM. Текст генерируется в реальном времени, после чего его можно отредактировать и скопировать в медкарту.

---

## Текущее состояние

Проект полностью реализован и готов к деплою. Реализованы все четыре типа документов, пять LLM-провайдеров и ряд расширенных функций поверх базовой спецификации.

### Реализованные функции

**Базовые**
- 4 типа документов: первичный осмотр, повторный осмотр, врачебная комиссия (ВК), МСЭК
- Потоковая генерация — текст появляется токен за токеном, можно остановить в любой момент
- Few-shot примеры для каждого типа документа — синтетические, без реальных данных пациентов
- Бюджет токенов с автоматическим уменьшением числа примеров при переполнении
- Настройки провайдера сохраняются в `localStorage`; клинические данные нигде не хранятся

**Расширенные (сверх спецификации)**
- **Встроенное редактирование с LLM** — выделите фрагмент готового документа, введите инструкцию на естественном языке, получите предложение правки потоком; стек undo/redo до 20 правок
- **Многоходовой контекст** — последовательные запросы учитывают историю разговора; контекст можно сбросить вручную или при смене типа документа
- **История сессии** — последние 15 сгенерированных документов автоматически сохраняются в боковой панели; любой можно восстановить

## Архитектура

```
Браузер → Cloudflare Worker (CORS-прокси) → LLM API
        ←          SSE-поток              ←
```

Браузер не может напрямую обращаться к LLM API из-за CORS. Cloudflare Worker выступает прокси: принимает запрос, проверяет хост по списку разрешённых (`ALLOWED_HOSTS`), пробрасывает тело и заголовки, возвращает поток. Worker не логирует и не буферизует содержимое.

## Быстрый старт

### Требования

- Node.js 18+
- Аккаунт Cloudflare (бесплатный) — для Worker-прокси
- API-ключ любого поддерживаемого провайдера

### Установка

```bash
git clone https://github.com/<your-username>/pnd-doc.git
cd pnd-doc
npm install
```

### Запуск локально

```bash
# Терминал 1 — CORS-прокси
cd worker && npx wrangler dev

# Терминал 2 — Vite dev server
cp .env.example .env.local   # VITE_WORKER_URL=http://localhost:8787
npm run dev
```

Приложение: `http://localhost:5173`. При первом запуске автоматически откроется окно настроек.

### Проверка типов

```bash
npm run type-check
```

### Продакшен-сборка

```bash
npm run build   # → dist/
```

Папка `dist/` — статический сайт, деплоится на Cloudflare Pages, Vercel, Netlify или любой статический хостинг.

### Деплой Worker

```bash
cd worker
npx wrangler login    # один раз
npx wrangler deploy   # → https://pnd-doc-proxy.<subdomain>.workers.dev
```

После деплоя обновите `VITE_WORKER_URL` в переменных окружения хостинга.

## Приватность

- **API-ключи** — только `localStorage` браузера, никуда не передаются кроме прокси-запросов
- **Клинический текст** — только в оперативной памяти; отправляется исключительно выбранному LLM-провайдеру через Worker; нигде не сохраняется
- **Worker** — stateless, не логирует и не хранит тело запросов
- **Примеры** — синтетические данные, без реальных пациентов
- Никакой аналитики, телеметрии и трекинга
