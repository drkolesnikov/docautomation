# ПНД.doc

Инструмент для автоматизации клинической документации в психоневрологическом диспансере.

Врач вводит свободные заметки → выбирает тип документа → получает готовый структурированный документ для вклейки в медицинскую карту. Форматирование выполняется через LLM (большую языковую модель) с использованием few-shot примеров реальной документации.

---

## Возможности

- **4 типа документов:** первичный осмотр, повторный осмотр, врачебная комиссия, МСЭК
- **Выбор LLM-провайдера:** OpenAI, DeepSeek, Anthropic Claude, Google Gemini, YandexGPT, или любой OpenAI-совместимый сервер (ollama, vLLM, LM Studio)
- **Потоковая генерация:** текст появляется в реальном времени, можно остановить в любой момент
- **Few-shot примеры:** LLM обучается формату, стилю и терминологии на основе примеров документов
- **Приватность:** данные пациентов не сохраняются — только в оперативной памяти на время сессии

## Быстрый старт

### Требования

- Node.js 18+
- npm
- Аккаунт Cloudflare (бесплатный) — для CORS-прокси
- API-ключ любого поддерживаемого LLM-провайдера

### Установка

```bash
git clone https://github.com/<your-username>/pnd-doc.git
cd pnd-doc
npm install
```

### Настройка прокси (Cloudflare Worker)

Браузер не может напрямую обращаться к API провайдеров из-за CORS. Приложение использует минимальный Cloudflare Worker в качестве прокси.

```bash
cd worker
npx wrangler login
npx wrangler deploy
```

После деплоя вы получите URL вида `https://pnd-doc-proxy.<subdomain>.workers.dev`.

### Настройка переменных окружения

```bash
cp .env.example .env.local
```

Отредактируйте `.env.local`:
```
VITE_WORKER_URL=https://pnd-doc-proxy.<your-subdomain>.workers.dev
```

### Запуск

```bash
npm run dev
```

Откройте `http://localhost:5173`. При первом запуске автоматически откроется окно настроек — введите API-ключ и выберите провайдера.

### Сборка для продакшена

```bash
npm run build
```

Папка `dist/` — статический сайт. Можно разместить на Cloudflare Pages, Vercel, Netlify, или любом статическом хостинге.

## Поддерживаемые провайдеры

| Провайдер | Формат API | Что нужно |
|-----------|-----------|-----------|
| OpenAI | Chat Completions | API-ключ |
| DeepSeek | Chat Completions | API-ключ |
| Anthropic Claude | Messages API | API-ключ |
| Google Gemini | GenerateContent | API-ключ |
| YandexGPT | YandexGPT API | API-ключ + Folder ID |
| ollama / vLLM / LM Studio | Chat Completions | Base URL (ключ не нужен) |

### Добавление нового провайдера

Если провайдер поддерживает формат OpenAI Chat Completions (большинство поддерживают) — выберите «Custom (OpenAI-совместимый)» в настройках и укажите Base URL. Новый код не нужен.

Если у провайдера собственный формат API — потребуется новый адаптер в `/src/providers/`.

## Как это работает

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Браузер    │────→│   Worker     │────→│  LLM API     │
│              │     │  (прокси)    │     │              │
│  Заметки +   │     │  Пробрасывает│     │  Генерирует  │
│  тип документа│     │  запрос и    │     │  документ    │
│              │←────│  поток       │←────│              │
│  Готовый     │     │              │     │              │
│  документ    │     │              │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
```

1. Врач выбирает тип документа и вводит заметки
2. Приложение собирает промпт: инструкция + правила + few-shot примеры
3. Запрос уходит через Worker-прокси к LLM-провайдеру
4. Ответ стримится обратно и отображается в реальном времени
5. Врач редактирует результат при необходимости и копирует в медкарту

## Few-shot примеры

Примеры документов лежат в `/src/examples/` — по файлу на каждый тип документа. Каждый пример — пара «заметки врача → готовый документ». Они включаются в промпт, чтобы LLM понимала формат, стиль и терминологию.

Все примеры **синтетические** — без реальных данных пациентов.

Формат (`examples.json`):
```json
[
  {
    "id": "pervichniy-001",
    "input": "Свободные заметки врача...",
    "output": "Готовый документ в стандартном формате...",
    "tokenEstimate": 3200,
    "metadata": {
      "diagnosis_category": "F20",
      "complexity": "typical"
    }
  }
]
```

## Структура проекта

```
├── src/
│   ├── components/       # React-компоненты UI
│   ├── providers/        # Адаптеры LLM-провайдеров
│   ├── prompts/          # Шаблоны системных промптов
│   ├── examples/         # Few-shot примеры (JSON)
│   ├── hooks/            # React-хуки (стриминг, токены)
│   ├── context/          # React Context (состояние)
│   └── utils/            # proxyFetch, tokenEstimator, clipboard
├── worker/               # Cloudflare Worker (CORS-прокси)
├── Claude.md             # Спецификация для AI-ассистента
└── ARCHITECTURE.md       # Обоснование архитектурных решений
```

## Приватность

- API-ключи хранятся только в `localStorage` браузера
- Текст заметок — только в оперативной памяти, отправляется только выбранному LLM-провайдеру
- Worker-прокси не логирует и не сохраняет содержимое запросов
- Примеры документов — синтетические данные, без реальных пациентов
- Никакой аналитики, телеметрии или трекинга
- После закрытия вкладки клинические данные не сохраняются
